## Grid

The 8x8 pads are notes 11-88, bottom-left first (the same numbering as the
Launchpad Pro MK3). The pad window shows the MPC clip matrix; the arrows move
the window. Row 0 is the top row of pads. Pad press launches the clip under
it; a pad press selects and launches the clip under it.

```
  top row:  91 Up   92 Down   93 Left   94 Right   95 Session
            96 Drums (MPC pads)   97 Keys (Pad Perform)
            98 User (Q-Link page)
  right:    89 Scene 1   79 Scene 2   69 Scene 3   59 Scene 4   49 Scene 5
            39 Scene 6   29 Scene 7   19 MIXER menu (bottom-right corner)
```

There is no Shift: the Novation logo is not a button on the Mini MK3.

## MIXER menu (CC 19)

All six per-track functions are exposed at the same time, one row each, one
column per track (the columns follow the clip window, so the mixer lines up
with the clip grid):

```
  row 0 (notes 81-88)   Pages (global, not per track):
      col 0 (note 81): Volume (cyan tint)
      col 1 (note 82): Pan (magenta tint)
      col 2 (note 83): Send — cycles 1-4 on the arrows (tint follows the send)
      col 3 (note 84): Tempo page (white)
      col 4 (note 85): Swing page (yellow)
      col 5 (note 86): Q-Link page (blue tint)
      col 6 (note 87): Tap tempo (grey)
      col 7 (note 88): Click — cyan while the metronome runs
  row 1 (notes 71-78)   Transport (global, not per track):
      col 0 (note 71): Play (green playing, orange loop armed)
      col 1 (note 72): Record (red)
      col 2 (note 73): Stop (stop; stop again = return to zero)
  row 2 (notes 61-68)   Record (blue; red while recording, dim red armed): one pad per track column
  row 3 (notes 51-58)   Stop clips (grey): one pad per track column
  row 4 (notes 41-48)   Mute (orange): one pad per track column
  row 5 (notes 31-38)   Solo (yellow): one pad per track column
  row 6 (notes 21-28)   Record arm (red): one pad per track column
  row 7 (notes 11-18)   Select track (track colour, white = current): one pad per track column
```

Press CC 19 again (or Session) to close the mixer; CC 19 also closes any open
page (fader menu, tempo, swing, Q-Link) first. The record row starts a
clip recording (arm + trigger the first empty slot) and stops it again.

## Buttons

### Top row (CC 91-98)

| CC | Button | Press |
| --- | --- | --- |
| 91 | Up | window up / page value up (hold repeats) |
| 92 | Down | window down / page value down (hold repeats) |
| 93 | Left | move the clip window left (sends menu: previous send) |
| 94 | Right | move the clip window right (sends menu: next send) |
| 95 | Session | clip grid (leaves every page) |
| 96 | Drums | pads mode; repeat: 16-pad quadrant <-> 64 pads, then off |
| 97 | Keys | play the track's pads from the grid — kits plainly, melodic tracks with Pad Perform chords (repeat: leave) |
| 98 | User | Q-Link page (repeat: page 2, then exit) |

| 79 | Scene 2 | launch scene 2 |
| 69 | Scene 3 | launch scene 3 |
| 59 | Scene 4 | launch scene 4 |
| 49 | Scene 5 | launch scene 5 |
| 39 | Scene 6 | launch scene 6 |
| 29 | Scene 7 | launch scene 7 |
| 19 | Mixer | open/close the MIXER menu (grid) |
